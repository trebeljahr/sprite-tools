# Privacy

Sprite Tools runs almost entirely in your browser. Sprite images you
upload never leave your machine. Only the AI tools send anything out, and
only when you use them.

## What we count

The site counts visits with a self-hosted
[Plausible](https://plausible.io) instance. Plausible sets no cookies
and stores nothing in your browser. It does not follow you to other
sites, and no ad network sees the data.

It counts two things, as totals across all visitors:

- **Pageviews**: which pages get opened, and from which referring site.
- **Tool events**: a handful of named events, such as "exported a GIF"
  or "loaded a sample". Each event carries only the tool, the export
  format and counts like the number of frames. It never carries file
  names, image data or text you typed.

Plausible also reads the browser, operating system and country from
each request. It does not store IP addresses. To count unique visitors
it uses a hash that changes every day, so one day's visit cannot be
linked to the next.

To leave your own visits out of the counts, open the browser console on
this site and run `localStorage.plausible_ignore = "true"`. Plausible
reads that key and then sends nothing from that browser.

## AI Character

[AI Character](/generate) makes images with xAI. How your prompt travels
depends on who pays:

- **Your own xAI key**: your browser sends the prompt and the key straight
  to xAI. The key stays in the page's memory until you close the tab. It
  never reaches the Sprite Tools server.
- **AI credit**: your browser sends the prompt to the Sprite Tools server,
  which passes it to xAI and sends the image back. The server keeps the
  price and time of each image, not the prompt or the image.

The key and the prompt reach xAI only when you press Generate.

xAI handles the prompt under [its own privacy policy](https://x.ai/legal/privacy-policy).

## Accounts and AI credit

An account exists only to hold AI credit. The server stores your name,
email address, a hash of your password and your credit balance. For each
session it stores the IP address and browser that signed in, and a
signed-in session sets one cookie. To slow down password guessing, the
server counts requests to the sign-in and account endpoints per IP
address. It keeps one counter per IP address and endpoint, with the time
of the last request.

For prepaid generations, the server keeps the request ID, model, provider,
reservation amount, result, credit outcome and request time. You can view
these records on the [usage dashboard](/usage). Historical records may lack
a model or credit outcome.

You buy credit through [Stripe](https://stripe.com/privacy). Stripe takes
your card details; the Sprite Tools server never sees them. The server
keeps the Stripe checkout ID, the amount and the time of each purchase.

## Error reports

A self-hosted [GlitchTip](https://glitchtip.com) instance receives
anonymous crash reports, so we can fix bugs we could not reproduce
locally. A report holds the stack trace and the URL of the page that
crashed. It holds no sprite data, and we log no IP address beyond what
the origin server naturally sees.

## What the tools keep in your browser

Some tools remember things on your device so they keep working across
pages and reloads. None of this is sent anywhere, and none of it is
used for counting visits.

- **IndexedDB `sprite-tools`**: the image you loaded, or the one you sent
  over from AI Character, so every tool page opens with the same source.
- **`sprite-tools:source-rev`** (localStorage): a timestamp that tells
  other open tabs the image changed.
- **`sprite-tools:tutorial:<tool>:dismissed`** (localStorage): set when
  you close a tool's tutorial, so it stays closed.
- **`donation-supported-at`** (localStorage): set when you come back
  from the donate page, so the site can say thanks.

Clear the site data in your browser's settings to remove all of it.

## Never stored on our server

- Sprite images, frames, or generated images.
- AI Character prompts.
- The contents of your clipboard.
- Your own xAI key.

## Source of truth

Visit counts and error reporting are off in local development and only
activate in production. Plausible only loads on sprites.trebeljahr.com,
and error reporting requires `NEXT_PUBLIC_GLITCHTIP_DSN` — if you
self-host Sprite Tools on another domain without setting it, neither
endpoint is contacted.
