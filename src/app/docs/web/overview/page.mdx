# Overview tab

The [**Overview**](/overview) tab is the one-pane-of-glass for everything the other tools do. Upload a sprite sheet once and you see **every frame composited** with:

- **Collision polygons** drawn in green on each cell
- **Pivot dots** in red on each cell
- **Cell index labels** (#0, #1, …) in the top-left of each cell
- **Dashed grid lines** showing the detected cell boundaries
- Optional **tag banners** — paste a tags JSON in the sidebar and each cell gets a colored border matching its tag

## Why it matters

When you're generating metadata across three separate tools (Collision, Pivot, Tags) it's easy to lose track of how they line up. Overview is the sanity check — "do my collision shapes actually match where I think my pivots are, across all frames?" The answer is visible at a glance.

It also **shares the source across tabs**. Drop a PNG here, then click Collision — the same sheet is already loaded, already sliced, already ready to tune. Swap to Pivot, Tags, Pixelate, Normals, Palette, or GIF: the source follows. Persistence is via IndexedDB, so it survives page reloads too.

## Controls

- **Alpha threshold** / **Simplify tolerance** — same values that feed the Collision page's polygon generation. Set them here to preview what the collision output will look like before going to the Collision tab to export.
- **Pivot preset** — bottom-center (for characters), center (for projectiles), corners (for 9-slice UI), etc.
- **Tags JSON** — paste the output of `sprite-tools tags` or the Tags tab to visualize which frames belong to which animation clip.

## Tips

- If the grid detection picks the wrong count, set **Columns** / **Rows** manually in the sidebar — the overlay updates immediately.
- The canvas is pixel-perfect; zoom and pan to inspect a single cell. `image-rendering: pixelated` is set so even tiny sprites stay crisp.
- Clear source? Upload a new file — it replaces the shared source in IndexedDB, which propagates to every other tab via a `storage` event.
