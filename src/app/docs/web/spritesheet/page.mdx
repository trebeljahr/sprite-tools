# Sheet Builder

[Open Sheet Builder](/spritesheet)

Sheet Builder turns video, GIFs, existing sprite sheets, or loose frame images into a clean exported sheet.

## When to use it

- You have a short animation and need individual frames.
- You have an existing sheet and want to split, crop, restitch, or export a different layout.
- You want chroma-key cleanup before sending frames into Collision, Pivot, Tags, Atlas, or GIF.

## Workflow

1. Choose **Video** or **Sheet**.
2. Drop, paste, or upload your source.
3. Tune background removal, crop, grid, and selected frames.
4. Export a stitched PNG sheet or a ZIP of individual frames.

When you arrive from [AI Animation](/docs/web/animate), the generated video is passed into Sheet Builder automatically.

## Margin and spacing

Sheets from Kenney, Tiled, TexturePacker, and most itch.io packs are not flush: there is a border around the sheet and a 1–2px gutter between cells. Splitting one as `width / cols` puts every cell boundary slightly off, so each frame picks up a strip of its neighbour. It looks almost right, which is why it usually survives until the sprite is animating on screen.

Under **Columns** and **Rows** on a **Sheet** source there is a **Margin & spacing** disclosure with six fields: margin left, top, right, and bottom, plus spacing X and Y — all in pixels. Auto-detection fills them in when it can read the sheet's padding, and opens the disclosure so you can check the numbers before splitting; the collapsed label summarises them (`· margin 1, spacing 2`).

Margin is per side here, unlike the CLI and MCP flags, which are per axis — so a sheet whose right border differs from its left can be split correctly in the browser and nowhere else.

The grid overlay on the preview honours the values. With padding set it draws both edges of every cell, so the lines fall on the gutters rather than through them — that is the fastest way to confirm the numbers are right before you split.

Padding has to tile the sheet exactly. When it does not, the fit error appears under the fields with the actual pixel counts and **Split Sheet** stays disabled until you fix it. Leaving everything at zero keeps the old behaviour: the cell size is `floor(width / cols)` and a non-divisible sheet just loses the remainder off the right and bottom edges.

## Duplicate frames

Video extracted at a fixed FPS and AI-generated frames often repeat the same pose. **Select unique**, in the Frame Selection header, deselects every frame that duplicates an earlier one. Nothing is deleted: the duplicates stay in the grid, unselected, so you can see which frames go and select any of them again by hand. The preview, the stitched sheet, and the ZIP use the selected frames only.

- Set **Tolerance** next to the button before you press it. Hover the box for the full definition.
- The button replaces the current selection. Any frames you deselected by hand are selected again if they are not duplicates.
- Frames are compared as the grid shows them, after background removal and crop. If you change those settings, press **Select unique** again.
- The header then reads "N duplicates deselected" or "No duplicates found".

**Tolerance** is the mean absolute difference per RGBA channel on a 0-255 scale, averaged over every channel of every pixel. 0 requires byte-identical frames. 1 means the average channel differs by 1/255 (~0.4%), the scale of rounding noise from lossy video compression or canvas alpha premultiplication. 2-4 absorbs a handful of stray pixels. Above ~8 visibly different poses start collapsing.

A frame counts as a duplicate when its difference is at or below the tolerance. Alpha counts: a difference in transparency adds to the difference like a difference in colour, so at tolerance 0 two frames that differ only in transparency are never duplicates. Each frame is compared with the first frame of every group found so far, never with other duplicates, and the earliest frame of a group is the one kept.

Removing frames renumbers every frame after them, and animation tags are frame ranges. Build the sheet first and tag it afterwards in [Tags](/docs/web/tags). If you already have a tags file for a sheet, dedupe that sheet with `sprite-tools dedupe --tags` instead, which rewrites the ranges for you — see the [CLI reference](/docs/cli/reference#dedupe).

## CLI equivalents

Use the CLI for scriptable pieces of this workflow:

```bash
sprite-tools detect sheet.png
sprite-tools slice sheet.png --out-dir frames --json frames.json
sprite-tools slice tileset.png --cols 8 --rows 6 --margin 1 --spacing 2 --out-dir tiles
sprite-tools trim sprite.png --padding 1 -o tight.png
sprite-tools atlas frames/*.png -o atlas.png --json atlas.json
sprite-tools dedupe sheet.png --threshold 1 --tags tags.json --tags-out tags-deduped.json --sheet clean.png
```

The browser tool is the best fit for manual frame selection, visual crop tuning, and video-to-sheet cleanup.
