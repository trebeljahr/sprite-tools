# Support

Use the channel that best matches the problem:

- **Bug reports**: open a GitHub issue with the bug report template.
- **Feature ideas**: open a GitHub issue with the feature request template.
- **Questions and usage help**: open a GitHub issue and include the command, input shape, or workflow you are trying.
- **Security reports**: follow `SECURITY.md` instead of opening a public issue.

Please include the sprite-tools version, Node version, operating system, and the exact command or page involved when that context is relevant.
