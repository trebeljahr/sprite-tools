# Security Policy

## Supported versions

Security fixes target the latest released version of `@trebeljahr/sprite-tools`.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting or open a private security advisory for this repository.

Include:

- A short description of the issue.
- Steps to reproduce.
- Affected version or commit.
- Impact and any known workaround.

Maintainers will acknowledge the report, investigate, and coordinate a fix before public disclosure.
